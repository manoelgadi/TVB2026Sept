## 🧩 Part 1 — Build First, Code Later

We will start with **No-Code / Low-Code AI tools**.

👉 **Start by looking at the workshop PDF in this repository.**

We will complete two practical exercises:

### 🌐 Practice 1 — Build Your Startup Waiting-List Landing Page

Use **[v0.app](https://v0.app/)** to design and build a landing page for your startup.

You will:

- Create a landing page for your startup
- Add an **email waiting list**
- Display the number of registrations
- Make the waiting-list data downloadable
- Deploy the application publicly using **Vercel**
- Test the deployed application and verify that the waiting list works

**Goal:** Go from a startup idea to a **working, publicly deployed web application** using AI and No-Code/Low-Code tools.

---

### 🎵 Practice 2 — Make a Jingle for Your Startup

Use **[Suno AI](https://suno.com/)** to create an original jingle for your startup.

You will:

- Define the key message of your startup
- Create lyrics that communicate your value proposition
- Choose a musical style
- Generate your startup jingle with **Suno AI**
- Experiment with different versions until you find one that represents your startup

**Goal:** Explore how Generative AI can help create **branding and marketing content**, not just software.

---

These two exercises demonstrate how quickly Generative AI can help transform a startup concept into something people can **see, use, and hear**.
